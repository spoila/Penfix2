# PenFix 2

Separate Android app build based on the PenFix2 source ZIP.

- Display name: PenFix 2
- Application ID: `com.example.penfix2` (separate from the original `com.example.penfix`)
- Build: GitHub Actions workflow `Build PenFix 2 APK`

The workflow builds a debug APK and uploads it as the `PenFix2-debug-apk` artifact.
